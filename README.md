# 恋爱星

一个仅自己可见的恋爱手账，保留粉色玻璃与可爱图标，用来整理日常、照片、纪念日、心愿和待办。

## 私密范围

仅独立恋爱星管理员可以登录和访问内容。访客、普通博客账号和旧伴侣账号都无权读取；旧公开标记不再开放记录、纪念日或照片，公开预览和伴侣邀请入口已关闭。旧账号与内容保留，不会因为收紧权限删除历史。

博客的管理员身份不会自动登录恋爱星。首次由博客站主在 `/admin/love` 创建独立管理员，再从 `/love/login` 进入。没有默认密码、公开注册或邀请码注册。

## 功能

- 日常时间线、搜索、那年今日、每条记录一张照片。
- 恋爱日期、在一起天数、纪念日倒数及闰日处理。
- 私密心愿清单，可以完成和重新打开。
- 我的待办：项目分组、日期、优先级、负责人（仅自己），支持完成、归档和恢复。
- 记录回收站；照片逐次验证权限，并移除 EXIF 后重新编码。

## 独立运行

需要 Python 3.10 或更新版本：

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe manage.py init-admin
.venv\Scripts\python.exe serve.py
```

打开 `http://127.0.0.1:8002`。初始化命令在本机交互询问密码，不把密码放在命令行。用户名 1–10 字符、区分大小写，新密码 8–15 字符；已有长密码仍能登录。

## 数据与备份

`LOVE_DATA_DIR` 默认是 `data/`；`love.db`、独立 `secret.key` 和 `uploads/` 均不会上传 Git。默认仅监听本机，HTTPS 部署时设置 `LOVE_HTTPS=1`。独立备份时先停止服务，再完整复制 data 目录（含 WAL）。

博客挂载版本使用 `blogsite/data/love_star/`，完整备份会快照数据库、密钥和照片。服务器及备份的持有者仍可访问磁盘上的数据。

照片 ≤8 MB / 2500 万像素，转为最长边 2048 的 JPEG；照片空间 200 MB。记录最多 1000 条，纪念日 100 个，心愿 200 条，未归档待办 500 个。未接入邮件或系统推送。

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试覆盖旧公开内容保护、旧伴侣会话拒绝、私密照片、CSRF、文本转义、待办、归档恢复、持久化与日期倒数。

待办按项目显示进行中、今日与逾期、已完成、归档数量；完成、归档、恢复与编辑后保留当前筛选。归档项目仍可在项目选择器中找到。所有待办继续仅站主可见。
