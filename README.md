# 恋爱星

给一对情侣的星光手账：记录恋爱日常，收藏照片，期待纪念日，完成共同心愿。

这是独立的 Flask 项目，账号、数据库、会话密钥均与 L5 博客、听歌云、文学角分开。L5 博客内也可以通过 `/love/` 挂载同一套代码。

## 谁能做什么

| 身份 | 权限 |
| --- | --- |
| 恋爱星管理员（1 位） | 配置昵称与起始日期，邀请或停用伴侣，管理全部记录与纪念日 |
| 伴侣（最多 1 个启用账号） | 查看两人内容，写记录、修改自己的记录，一起完成心愿 |
| 访客 | 无需注册，只读主动公开的记录和纪念日 |

**默认私密**：文字、照片、纪念日都不会自动公开。每次公开需勾选确认；昵称、起始日期与在一起天数另有公开开关。共同心愿始终仅两人可见。

不开放普通注册。管理员生成的伴侣邀请码只能用一次，24 小时后过期；生成新邀请使旧邀请失效。停用伴侣会立即使其已有登录会话失效，历史记录仍保留；可重新启用原账号，需重新登录。一个空间不适合给多对情侣共用。

## 小功能

- 恋爱时间线、关键词找回忆、那年今日。
- 一条记录一张照片，按记录权限检查图片访问，移除照片 EXIF 后重新编码。
- 在一起天数，以及下一个 100 / 365 / 520 / 1000 天等小庆祝节点。
- 纪念日倒数，每年重复或只此一次；闰日平年按 2 月 28 日计算。
- 两人共同心愿清单，可以完成、重新打开。
- 记录回收站，可恢复；恢复后先设为私密。
- 管理员可预览公开时间线。

## 本机独立运行

需要 Python 3.10 或更新版本。在 PowerShell 执行：

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe manage.py init-admin
.venv\Scripts\python.exe serve.py
```

本机命令会交互询问管理员用户名和密码，不会显示密码，也不会把密码放在命令行中。用户名 1–10 个字符、区分大小写，密码 8–15 个字符。打开 http://127.0.0.1:8002 ，登录后进入「星球管理 → 设置与伴侣账号」。

没有默认账号、默认密码或公开的管理员注册页面。没有设置管理员时，公共页面显示空状态，访客不能抢先成为管理员。

## 从博客开始

博客站主打开 `/admin/love`，设置恋爱星的独立管理员账号，再到 `/love/login` 登录。这个过程需要已登录的博客管理员，不会把已有博客访客升级成恋爱星成员。

原博客文章保留在后台与文章归档，未经选择不会迁入恋爱星，也不会被当作恋爱记录公开。

## 数据与部署

| 配置 | 默认值 |
| --- | --- |
| `LOVE_DATA_DIR` | 项目下 `data/` |
| `LOVE_HOST` | `127.0.0.1` |
| `PORT` | `8002` |
| `LOVE_HTTPS` | HTTPS 部署时设为 `1` |

`data/love.db` 是 SQLite 数据库；`data/secret.key` 为独立会话密钥；`data/uploads/` 保存经过处理的照片。均从 Git 排除。独立运行时，停止服务后复制整个 `data/` 备份，包含可能存在的 WAL 文件；恢复时保留密钥。

博客挂载版本使用 `blogsite/data/love_star/`，博客的完整备份会同时快照恋爱星数据库、密钥与照片。两个应用的数据库独立，仍可以由拥有服务器和备份权限的站主管理；站内私密权限不等于端到端加密。

默认仅监听本机，对外使用请配置 HTTPS。每张照片 ≤8 MB / 2500 万像素，缩放至最长边 2048 后转为 JPEG；当前照片空间限额 200 MB。记录最多 1000 条、纪念日 100 个、心愿 200 条。当前未接入邮件通知、推送和多人情侣空间。

## 验证

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试使用临时数据库，覆盖邀请过期／重放、角色与记录权限、照片访问、公开确认、会话失效、EXIF 清理、回收站、倒数和页面渲染。

核心包 `lovestar/` 可独立复制部署，不依赖博客目录。`lovestar.integration.mount()` 通过 WSGI 路径挂载，不共享宿主会话 Cookie。


## 两人待办

「待办」支持项目分组、备注、截止日期、普通/优先、分配负责人或一起完成，以及进行中、今日与逾期、已完成、归档筛选。两人均可打勾或重新打开，创建者和管理员可编辑与归档；归档可以恢复。首页仅在两人空间展示未完成待办，访客和公开预览不会出现待办内容。待办不会公开，也不发送邮件或系统通知。

升级只会创建 `todos` 新表，不修改现有记录。项目最多保留 500 个未归档待办；通过归档整理旧任务。
